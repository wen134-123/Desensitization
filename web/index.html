识别范围

公司/单位、人名、电话、身份证、银行卡/账号、邮箱、地址、报价/金额、项目代号、统一社会信用代码。支持正文、表格、嵌套表格、页眉页脚与文本框。

三种处理策略

假名替换：生成占位符或拟真假值，写入映射表，可逐字还原。星号遮盖：保留部分字符，便于内部比对，不可还原。严格删除：整段抹除，不可还原。

可逆还原

假名替换的每个实体都会进入映射表。设置口令后映射以 PBKDF2 + Fernet 加密保存，必须同时持有脱敏件、映射文件和口令才能还原。

建议的操作顺序

上传文件 → 设置类别策略 → 开始识别 → 逐条复核误标/漏标 → 预览确认 → 导出脱敏文档、映射与报告。

当前边界

当前版本聚焦 .docx / .txt / .md。PDF、Excel、扫描件 OCR 尚未接入；图片、印章、手写签名需要人工处理。正式外发前请再通读一遍脱敏件。
